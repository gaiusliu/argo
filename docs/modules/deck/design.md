# deck

## 概述

deck 是 Argo 的工具管理模块。负责工具的注册、发现和调用，对上（helm）暴露查询和调用接口，对下通过 `Tool` 接口统一 builtin 和 CLI 两种工具来源。deck 不依赖其他 Argo 模块。

## 核心概念

| 概念 | 说明 |
|---|---|
| Tool | 工具的统一抽象，所有工具实现名称、描述、来源、执行 |
| ToolResult | 工具调用结果，包含输出内容、成功/失败状态、调试信息 |
| ToolSource | 工具来源：builtin（内置）或 cli（外部命令行） |
| builtinTool | 内置工具，执行逻辑为 Go 函数 |
| cliTool | 外部 CLI 工具，用户自行安装的二进制，通过子进程执行 |
| Agentic Search | LLM 调用 List / Lookup 自行发现和选择工具 |

## 流程

### 启动注册

```
argo 启动
  ├─ 注册所有内置工具（包括 List/Lookup 自身）
  └─ 加载外部工具配置
       └─ 逐条注册外部工具
            → 注册表就绪
```

### 运行时发现（Agentic Search）

```
LLM 需要工具
  → 调用 List
    → 拿到全部工具名列表
      → 需要看某个工具的参数？
        ├─ 是 → 调用 Lookup
        │        → 拿到该工具的元数据
        │        → 调用 Execute
        └─ 否 → 直接调用 Execute
```

### 工具选择

```
List
  → 遍历注册表
  → 按注册顺序返回全部工具名及描述

Lookup(工具名)
  → 在注册表中精确匹配
  → 命中 → 返回工具的完整元数据
  → 未命中 → 返回未找到
```

### 工具调用

```
helm 发起执行命令
  → 校验参数
  → 按工具类型执行：
    ├─ 内置工具 → 调用注册时绑定的处理函数
    └─ CLI 工具 → 参数转命令行 → 启动子进程执行
  → 返回结果给 helm
```

### 工具结果处理

```
ToolResult 返回
  → Output 超出上限？
    ├─ 是 → 按截断策略处理（保留头部 / 尾部 / 头尾）
    │        → 完整原文写入存储
    │        → 截断结果返回 helm
    └─ 否 → 直接返回 helm
```

## 行为合约

### 工具发现与注册

- 内置工具在 argo 启动时显式注册
- 外部 CLI 工具从配置文件加载后逐条注册
- 注册冲突规则：builtin 优先，外部工具同名报错
- Tool 元数据必须包含：名称（唯一标识）、描述（LLM 可读的自然语言）。CLI 工具的参数由 LLM 通过 `--help` 自行发现（详见 DEC-002）

### 工具选择

- List / Lookup 本身也是内置工具，支持 Agentic Search
- List 按注册顺序返回，保证稳定
- Lookup 按工具名精确匹配

### 工具调用

- 所有工具通过统一接口执行，传入上下文和参数
- 上下文超时或取消时执行必须终止
- 内置工具参数从 params map 中直接提取，CLI 工具参数由 LLM 通过 `--help` 自行组装

### 工具结果处理

- 结果包含输出内容、成功/失败状态、调试信息
- 输出超过上限时按策略截断，完整原文持久化存储

## 内置工具集

| 工具 | 职责 |
|---|---|
| `bash` | 执行 Shell 命令，兜底覆盖所有操作 |
| `read` | 流式读取文件内容，带行号返回，支持 offset/limit 翻页 |
| `write` | 创建或覆盖写入文件 |
| `edit` | 精确替换文件中的指定片段，支持 replace_all |
| `grep` | 按正则搜索文件内容，返回 "文件:行号:内容" 格式 |
| `glob` | 按文件名模式匹配文件，返回路径列表 |
| `list` | 列出注册表中全部工具的名称和描述 |
| `lookup` | 按名称查找工具，返回详细元数据 |
